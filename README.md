# Interesting Algorithms

Это собрание разнообразных алгоритмов, программ и всего остального, чей размер слишком мал для того, чтобы выделить это в отдельный репозиторий. Поэтому это собрано здесь. В решении используется чистый .NET, для реализации тестов - фреймворк NUnit.

## Roadmap

### К репозиторию

- Добавить сайт-документацию к каждому проекту через DocFX.
- Настроить CI/CD на GitHub Actions.
- Реализовать бенчмарки с BenchmarkDotNet.

### К проекту

- Добавлять другие разнообразные интересные вещи:
	- Сортировка
	- Графовые
	- Сжатия
	- Криптографии
- Написать документацию к коду в виде docstrings.
- Покрыть тестами более 80% кода.
- Переписать тесты в более продвинутом виде для NUnit (через атрибуты и другие фичи фреймворка).
