# Projects

This directory contains the main product and domain projects in the repository. Most entries are .NET projects included in [`../NovoDwarf.slnx`](../NovoDwarf.slnx); SmartHome also has a separate solution, and the Home area contains embedded and Home Assistant code.

## Navigation

| Project | Type | Description |
|---|---|---|
| [`Mathematics`](Mathematics/README.md) | .NET libraries, MAUI app | Mathematical modules for numerical methods, probability, graphs, optimization, graphics, processing, and related utilities. |
| [`Modeling`](Modeling/README.md) | .NET libraries, console examples | Simulation libraries for DeltaT and event-driven models, plus logging and metrics. |
| [`Procedural.NET`](Procedural.NET/README.md) | .NET libraries, Avalonia app | Procedural graph runtime, storage, node libraries, and desktop designer. |
| [`Grekov`](Grekov/README.md) | .NET libraries, console example | Definition/package framework with localization, assembly loading, and JSON/XML readers. |
| [`SultanDynasty`](SultanDynasty/README.md) | .NET libraries, Avalonia app | Game/simulation prototype with definitions, ECS components, character generation, simulation, and UI. |
| [`Home`](Home/README.md) | .NET, MAUI, Home Assistant, ESP32 | Smart home automation projects, bot integrations, mobile client, IR control, and embedded sensor code. |
| [`Godot`](Godot/README.md) | .NET library | Godot/Slang integration experiments. |
